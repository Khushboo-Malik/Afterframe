# AfterFrame frontend

The Next.js 16 site for AfterFrame: home, `/trips`, the trip map at `/v/[videoKey]`, and `/how-it-works`.

```bash
cp .env.example .env.local   # BACKEND_URL, the Maps browser key and Map ID
npm install
npm run dev                  # http://localhost:3000 (the Django API must be running on :8000)
```

See the [main README](../README.md) for the full setup and architecture.
